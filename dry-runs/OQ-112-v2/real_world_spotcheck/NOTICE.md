# Real-world spot check

The 12 `.eml` files in this directory are **not part of the scored 28-file
corpus** (`corpus/` + `MANIFEST.csv` + `expected/`). They are real,
client-generated sample emails taken unmodified from
[mailgun/talon](https://github.com/mailgun/talon)'s own test fixtures
(`tests/fixtures/standard_replies/`), fetched 2026-07-28 from the GitHub
raw content API. Talon is Mailgun's open-source email reply-parsing
library; these fixtures are real quote-block samples captured from Gmail,
Outlook, Apple Mail, Yahoo, AOL, Comcast, Hotmail, Android, iPhone,
Sparrow, and Thunderbird, used to test exactly the "strip the quoted
history, keep the new reply" task this harness also performs.

**License:** talon is Apache License 2.0. Redistributed here unmodified,
under the same license, for evaluation purposes.

**Why they're here:** the scored corpus in `corpus/` is entirely synthetic
(see README's "Licensing / privacy" section for why). Failure-class self-review
for this project specifically flags a self-authored corpus tested only
against a harness also built for this project as a blind spot — a high
score would mostly prove the corpus and the harness agree with each other.
Running the same naive extractor against genuinely independent, real
client output is a check on that: see `spotcheck_report.txt` (generated by
`scripts/run_real_world_spotcheck.py`) and the "Real-world spot check"
section of the top-level README for what it found.
